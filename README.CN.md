## 核心特性

### 惊艳视觉与灵动交互
- **WinUI 3 & Win2D 驱动：** 丝滑的现代 UI 与硬件加速渲染，带来极致流畅的动画反馈与原生的 Windows 11 视觉体验。
- **高阶歌词动效：** 完美支持逐字、逐音节高亮（卡拉OK 效果）与长音余韵，远端歌词更有空间透视与模糊淡出特效，让每个字符随律动呼吸。
- **沉浸式动态背景：** 引入流体渐变、专辑封面模糊、迷雾及雪花粒子等多种视觉流派，结合实时音频频谱，音乐氛围瞬间拉满。
- **环境自适应变色龙：** 智能采样屏幕边缘或专辑封面的色彩，让播放器面板完美融入你的桌面环境。

### 全能生态与智能管理
- **海量音源可视化：** 不仅支持本地、SMB/FTP 流媒体播放，更无缝联动 Spotify、Apple Music、网易云等数十款主流播放器。
- **全场景窗口模式：** 纯粹的全屏专注模式、嵌入图标底层的壁纸模式（兼容 Wallpaper Engine）、极简的任务栏模式及灵活的侧边停靠，满足所有桌面布局。
- **精准匹配与 AI 赋能：** 智能元数据修正与本地缓存记忆。内置翻译引擎支持，更预留了本地大语言模型（LLM）的接入框架，探索前沿体验。
- **开放插件架构：** 强大的社区驱动能力，支持通过插件无限扩展歌词源、音译（如罗马音）及更多扩展功能。
- **你的专属音乐画报：** 一键生成黑胶、拍立得、赛博朋克等 10+ 款艺术歌词卡片，更有“年度听歌报告”揭秘你的专属音乐人设。
